# Marketing Performance Dashboard

Interactive marketing analytics dashboard recreating an Improvado-style 
executive summary view. Built for a Technical Customer Success assignment.

## Live Demo
🔗 [View Dashboard](https://tunombre.github.io/marketing-dashboard-recreation/Marketing_Dashboard_Recreation.html)

## What it includes
- 8 KPI cards with period-over-period deltas
- Channel Performance table (Paid Search, Paid Social, Programmatic, Organic)
- Data Source Performance breakdown by platform
- Campaign Performance rankings
- Monthly trend chart by channel
- Fully interactive filters — channel, data source, campaign, and exact date range

## Dataset
- 1,000 rows across 4 channels, 8 sources, and 12 campaigns
- Date range: Oct 2025 – Apr 2026
- Metrics: Impressions, Clicks, Spend, CTR, CPM, CPC, Conversions, Conversion Rate

## Tech stack
- HTML / CSS / JavaScript
- Chart.js (charts and sparklines)
- Python (data processing)
- No BI tool or framework required
